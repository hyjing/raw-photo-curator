# Security policy

Please do not open a public issue for a vulnerability that could expose local photos, execute
untrusted files, overwrite originals, or escape the loopback-only service boundary. Use GitHub's
private vulnerability reporting for this repository instead.

The project does not intentionally upload photos or feedback. Reports, previews, SQLite databases,
XMP sidecars, and exported originals remain local unless the user moves or shares them.

Only the latest release receives security fixes. Unsigned alpha builds should be verified against
the SHA-256 file attached to the corresponding GitHub Release.
